--------------------------------------------------------------------------------------------
---------DESCARGAR, CREAR Y ARRANCAR EL KAFKA + CREAR BROKER--------
--------------------------------------------------------------------------------------------

**Descargar la imagen de Kafka desde docker hub:
docker pull apache/Kafka

**Crear un contenedor con la imagen descargada y nombre brocker-kafka
docker run -d --name broker-kafka -p 9092:9092 apache/kafka:latest

**entrar en la teminal del contenedor arrancado 
1 ojo es powershell, no vale el cmd porque no admite los saltos de línea
2 solo vamos a tener una sola partición y un broker "factor de replicación" porque estamos en desarrollo, 
pero se deben tener más para garantizar la seguridad de los datos replicados y respaldo de broker.
docker exec -it [nombre del broker] [ruta a a topics en el kafka] --create --topic [nombre del topic] --particions [número particiones] --replication [numero de brokers de respaldo]
"""
docker exec -it broker-kafka /opt/kafka/bin/kafka-topics.sh `
--bootstrap-server localhost:9092 `
--create --topic products.commands  `
--partitions 1 --replication-factor 1
"""


**verificamos el broker 
"""
docker exec -it broker-kafka /opt/kafka/bin/kafka-topics.sh `
--bootstrap-server localhost:9092 --list
"""
devuelve: products.commands
